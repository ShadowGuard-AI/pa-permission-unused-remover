# pa-permission-unused-remover
Identifies and suggests removal of unused permissions based on application code analysis and historical usage. Uses static analysis to identify defined but unreferenced permissions, and dynamically monitors permissions actually used during runtime. - Focused on Tools for analyzing and assessing file system permissions

## Install
`git clone https://github.com/ShadowStrikeHQ/pa-permission-unused-remover`

## Usage
`./pa-permission-unused-remover [params]`

## Parameters
- `-h`: Show help message and exit
- `-e`: No description provided
- `-v`: No description provided
- `--check-file-permissions`: Check file permissions against a recommended permission set.
- `--report-unused-permissions`: No description provided
